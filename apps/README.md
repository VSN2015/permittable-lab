# apps

Generated Rails apps, one per supported Rails version. Do not hand-edit generated default files.

## rails-8_1

Generated by `bin/new-app 8.1` (Rails 8.1.4.1), which runs inside the lab image:

    gem install rails -v "~> 8.1.0" --no-document
    rails new rails-8_1 --skip-git --skip-test --skip-docker --skip-kamal --skip-thruster --database=postgresql

All flags were accepted by Rails 8.1. JS is the default (importmap).

The only edit to a generated default file: in `config/database.yml`, the `default:` section gained
`host: <%= ENV.fetch("DB_HOST", "db") %>`, `username: <%= ENV.fetch("DB_USER", "lab") %>`,
`password: <%= ENV.fetch("DB_PASSWORD", "lab") %>`.
